## 👻 About PhantomTabs

**PhantomTabs** is a Chrome monitoring and tab-management extension designed to provide users with a clear overview of their active browser tabs.

It helps users monitor open tabs, understand their current browsing session, and manage tabs through a simple and intuitive interface.

---

## 🚀 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/phantomtabs.git
```

### 2️⃣ Open Chrome Extensions

Open:

```text
chrome://extensions/
```

### 3️⃣ Enable Developer Mode

Turn on **Developer mode** from the extensions page.

### 4️⃣ Load PhantomTabs

Click:

```text
Load unpacked
```

Then select the PhantomTabs project folder.

### 5️⃣ Pin the Extension

Click the 🧩 **Extensions** icon in Chrome and pin **PhantomTabs** for quick access.
